# OpenTeleport brand decision

Confirmed 2026-11-04: retain the existing production landing and the selected **Shift** identity. The two displaced modules are the one production mark. No new landing design or logo is introduced by this cleanup.

- Light presentation: white background, charcoal type, cool grey supporting surfaces. Preserve the current optional dark theme and its existing amber accent.
- Typography: existing system sans serif for headings/body and monospace for commands. One clear headline and one message per campaign image.
- Imagery: white physical portals, paper/folders and charcoal objects. Use the same Shift mark and restrained palette in posts, clips, social previews and downloadable materials.
- Motion: retain the current portal/terminal transition and reduced-motion alternative. Future motion should explain transfer or completion.
- Production files: [Shift geometry](../../site/src/brand/shift.mjs), [assets](../../site/public/brand/shift/), [social previews](../../site/public/social/).
- Build: `node scripts/build-shift-brand.mjs` from the repository root. Shared generation is in `scripts/build-brand-assets.mjs`; source artwork is under Shift itself.

Historical alternatives live in [archive](archive/README.md). They do not belong in the site's public output. New explorations should be reviewed outside `site/public/` and should not replace the selected identity without an explicit decision.

[Selected external references](references-2026-11-04.md) are inspiration for composition, motion and communication, not additional OpenTeleport styles.
