# OpenTeleport 0.4.6 — verified Letta handoff

The Letta handoff now works with real Letta Code 0.34.39 local storage: agent records resolve to the correct memory directory, cron commands include the required description, and the generated scripts create a Git snapshot before restoring memory.

The generated Bash script was exercised in an isolated Linux container. Native memory status and export worked, and facts and skills survived the round trip. Cloud, model recall, scheduler execution and the PowerShell script remain unverified.

Grok Bot guidance now explains that Add to Memory accepts pasted text and asks a Bot to save shared user memory. This was checked against installed 0.78.1 code; live persistence and a genuine export remain open in #17.

The OpenClaw compatibility matrix passes on 2026.10.8 and 2026.10.10, with and without a Gateway. Its synthetic provider setup rejects model requests.
