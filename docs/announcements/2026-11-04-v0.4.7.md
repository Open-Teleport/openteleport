# OpenTeleport 0.4.7 — SSH and permission rules

Move an agent to or from another machine with `--to <app>@<host>` or `--from <app>@<host>`. OpenTeleport uses SSH and runs the same npm version remotely. Node.js 24+ is required on the remote.

Permission rules can now travel in the package. Supported targets receive native settings; rules that cannot be enforced are written as instructions and explicitly reported as approximations. Text instructions are not an enforced security boundary. Older OpenTeleport versions reject archives containing the new policy field; use 0.4.7 on both sides.

## Verified

- Release workflow: 2928 tests passed, 6 skipped on Linux, plus fresh-install package checks; PR CI passed on Linux, macOS and Windows.
- Public npm latest, matching release commit and provenance verified; production serves 0.4.7.
- A real Windows OpenSSH to Linux server round trip preserved a folder agent's facts and skill, including a cold remote npm download, copy and quoted-path checks.

## Still experimental

Native permission enforcement has fixture tests but no real-application enforcement check yet. The real SSH test covered the folder adapter with key authentication, not every remote application or interactive password prompt. Grok #17 and Codex #20 retain their documented verification gaps.
